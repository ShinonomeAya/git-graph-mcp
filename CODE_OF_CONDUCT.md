# Code of Conduct

`git-graph-mcp` is a small open-source project. Everyone who participates in
the project is expected to make the community useful, respectful, and safe.

## Expected behavior

- Be respectful and assume good intent.
- Focus feedback on the code, documentation, and user experience.
- Explain safety or compatibility concerns with concrete evidence.
- Protect private repository contents, credentials, and machine-specific paths.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing private information or credentials.
- Deliberately bypassing the project's safety boundaries or encouraging
  destructive Git actions without explicit user approval.
- Repeatedly disrupting issues, pull requests, or reviews.

## Enforcement

Report conduct concerns privately through the maintainer's GitHub profile. For
security vulnerabilities, follow [SECURITY.md](SECURITY.md) and do not include
secrets or exploit details in a public issue. The maintainer may remove or edit
content, close discussions, or restrict participation when needed to protect
the project community.
